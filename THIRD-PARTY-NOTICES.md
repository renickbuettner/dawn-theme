## Fonts

Dawn ships no web fonts. The frontend uses the visitor's system font stack.

## Frameworks and libraries

Dawn bundles no framework code. Bootstrap 5, Splide, GLightbox, Leaflet and
the Lucide icon sprite are shipped by the Renick.Content plugin, which
reproduces their licence notices in its own `THIRD-PARTY-NOTICES.md`.
